# 青岛国庆游玩计划 🌊

交互式地图导航版本，支持实时路线规划。

## 功能特性

- 📍 高德地图显示所有景点位置
- 🗺️ 实时路线规划（步行/驾车）
- 📱 一键调起高德地图导航
- 📅 Day 1 & Day 2 完整行程
- 🎯 点击景点查看详细信息

## 使用方法

1. 打开网页：https://你的用户名.github.io/qingdao-trip/
2. 选择 Day 1 或 Day 2 标签
3. 点击"我在这里"设置起点
4. 点击目标景点设置终点
5. 查看路线并点击"打开高德地图导航"

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "初始化青岛旅游计划"
git branch -M main
git remote add origin https://github.com/你的用户名/qingdao-trip.git
git push -u origin main
```

然后在 GitHub 仓库设置中开启 GitHub Pages。
